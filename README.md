# Agentic Ledger

A production-grade multi-agent AI system for financial reconciliation and processing. Built with Claude AI, LangChain4j, and GCP infrastructure.

## Overview

Agentic Ledger automates complex financial operations using intelligent agents that collaborate via MCP (Model Context Protocol). Perfect for reconciliation, compliance checking, and transaction processing.

## Features

- ✅ **Real-time Transaction Reconciliation** (<500ms latency)
- ✅ **Automated Corporate Actions Processing** (<2s latency)
- ✅ **Multi-Agent Collaboration** (Adversarial + Circular Refinement patterns)
- ✅ **MCP Tool Integration** (Security + Auditability)
- ✅ **Full Audit Trail** (BigQuery)
- ✅ **Zero Cost** (Deployed on GCP free tier)

## Tech Stack

- **Language**: Java 21
- **Agents**: LangChain4j + Claude API
- **Tools**: MCP (Model Context Protocol)
- **Cloud**: Google Cloud Platform (Cloud Run, Pub/Sub, Firestore)
- **Testing**: JUnit 5, Mockito
